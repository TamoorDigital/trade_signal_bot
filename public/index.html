Auto-Trade (MEXC)

OFF (tracking only)
When OFF, signals are scored, scanned and tracked exactly as normal — no real orders are placed. When ON, every new signal opens a REAL market order on MEXC sized from Leverage × USDT-per-trade, and every close (win/loss/partial/invalidated) closes that real position too. Real money, real risk.

Backup (survives Render restarts)

Render's free tier wipes local data on restart/redeploy. Export downloads everything (open + closed trades, feedback history, settings) as one JSON file — do this before anything risky, or periodically. Import restores from a previously exported file (requires the edit password) and always turns auto-trade OFF on restore, so a stale backup can never silently re-enable live trading.
